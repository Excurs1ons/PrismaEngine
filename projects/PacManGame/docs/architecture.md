## 三、渲染系统架构

### 3.1 渲染管线

```
┌─────────────────────────────────────────────────────────────────────┐
│                     Render Pipeline                             │
├─────────────────────────────────────────────────────────────────────┤
│                                                               │
│  1. Clear Pass               清除渲染目标                      │
│     └── glClearColor()                                           │
│                                                               │
│  2. Game Objects Pass       渲染游戏对象                        │
│     ├── Pellet Rendering     渲染豆子                           │
│     ├── Power Pellet        渲染能量药丸                        │
│     ├── Ghost Rendering      渲染幽灵                            │
│     └── Pac-Man Rendering   渲染吃豆人                          │
│                                                               │
│  3. 2D Lighting Pass        2D 光照计算                        │
│     ├── Pac-Man Light       吃豆人位置点光源                     │
│     ├── Ghost Lights         每个幽灵的点光源                    │
│     └── Ambient Light       环境光                             │
│                                                               │
│  4. UI Pass                 渲染 UI                            │
│     ├── Score Display        得分显示                            │
│     ├── Lives Display       生命显示                            │
│     └── Game Over/Menu     游戏结束/菜单                      │
│                                                               │
└─────────────────────────────────────────────────────────────────────┘
```

### 3.2 精灵渲染器

```
SpriteRenderer
├── 输入
│   ├── 纹理 (ITexture)
│   ├── 精灵区域 (SpriteRect)
│   ├── 颜色 (Color)
│   └── 变换
│       ├── 位置 (glm::vec2)
│       ├── 大小 (glm::vec2)
│       └── 旋转 (float)
└── 输出
    └── 顶点数据
        ├── Position (x, y)
        ├── TexCoord (u, v)
        └── Color (r, g, b, a)
```

### 3.3 2D 光照系统

```
Lighting2DPass
├── 光源类型
│   ├── Point Light          点光源（吃豆人、幽灵）
│   └── Directional Light    方向光（环境光）
├── 光照计算
│   ├── 距离衰减
│   └── 光源叠加
└── 渲染目标
    └── Light Map          光照贴图
```

## 五、碰撞检测系统

### 5.1 碰撞检测流程

```
1. 吃豆人移动
   └──> 检查目标格子是否是墙
        └── 是: 阻止移动
        └── 否: 更新位置

2. 豆子碰撞检测
   └──> 获取吃豆人当前格子
        └── 检查是否有豆子
             └── 有: 吃掉豆子，增加得分

3. 幽灵碰撞检测
   └──> 遍历所有幽灵
        └── AABB 碰撞检测
             └── 碰撞:
                  ├── 能量模式: 吃掉幽灵
                  └── 普通模式: 吃豆人死亡
```

### 5.2 穿墙（隧道）逻辑

```
当吃豆人到达隧道口时:
    if (x < 0) x = board_width;
    if (x >= board_width) x = 0;
```

## 九、性能优化策略

### 9.1 渲染优化

1. **批次渲染**: 相同纹理的精灵一次渲染
2. **视锥剔除**: 不渲染视口外的对象
3. **静态渲染**: 静态墙壁预渲染到纹理

### 9.2 逻辑优化

1. **空间分区**: 使用网格哈希表快速查找
2. **AI 更新频率**: 幽灵 AI 降频更新
3. **碰撞检测优化**: 仅检测相邻格子
